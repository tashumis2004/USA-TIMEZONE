# 🕒 USA Time Zones

A responsive web app that displays the current time in major US time zones.  
Built with **HTML, Bootstrap, Tailwind CSS, and JavaScript** in a single file.

---

## ✨ Features
- Live time updates every second
- Covers 6 major US time zones:
  - Eastern (ET)
  - Central (CT)
  - Mountain (MT)
  - Pacific (PT)
  - Alaska (AKT)
  - Hawaii (HAT)
- Responsive design using Bootstrap grid
- Modern styling with Tailwind CSS
- Dark Mode toggle 🌙☀️

---

## 🚀 Usage
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enjoy live USA time zones with dark mode support.
